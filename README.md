# MIORU

Виртуальная примерка одежды с 3D-аватаром. Покупатель создаёт свою цифровую копию, примеряет вещи онлайн и заказывает без ошибок с размером.

## Как это работает

1. **Аватар** — покупатель настраивает 3D-модель под свои параметры (рост, вес, телосложение, пол). Платформа подгружает реалистичную GLB-модель или генерирует процедурную.

2. **Примерка** — товар отображается на аватаре. Покупатель видит посадку по фигуре до покупки. Не фотография на модели, а честная визуализация.

3. **Заказ** — корзина, оформление, оплата. Покупатель получает XP за каждую покупку и растёт по VIP-уровням.

## Что внутри

```
apps/store/       Магазин (React + Vite) — SPA, статика, CDN
backend/api/      Бэкенд (Go) — заказы, клиенты, авторизация
packages/shared/  Общие типы и утилиты
```

Магазин отдаётся как статика — быстрая загрузка, дёшево хостить. Бэкенд — отдельный сервис, общается с магазином по REST API.

## Языки и регионы

Русский, English, Română — три языка из коробки. Тёмная и светлая темы.

## Разработка

```bash
# Магазин
cd apps/store && npm install && npm run dev

# Бэкенд
cd backend/api && go run ./cmd/server
```

Тесты: `npm test` (юнит), `npm run test:e2e` (скриншотные).
